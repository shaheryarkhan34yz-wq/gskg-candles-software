# GSKG CANDLES SOFTWARE

**AI-Powered Two-Candle Trading Analysis Dashboard**

GSKG CANDLES SOFTWARE is a modern trading analysis application designed to help users study market trends and evaluate potential next-candle movements.

## Features

- AI-assisted market analysis
- Two-step next-candle predictions
- CALL (UP), PUT (DOWN), and NO TRADE signals
- Signal confidence scores
- RSI, MACD, EMA, SMA, and Bollinger Bands analysis
- Candlestick patterns and price-action insights
- Support and resistance analysis
- Signal history and performance tracking
- Responsive dark-mode dashboard
- License key configuration

## Technology

- Next.js
- React
- TypeScript
- Lightweight Charts
